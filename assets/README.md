# Brand assets

Official brand assets for LeiCraftMC projects. Use these in apps, sites, and documentation rather
than recreating logos or picking arbitrary colors.

## Contents

- [`logos/`](logos/) — SVG logo, mark, and wordmark.
- [`colors/`](colors/) — color palette and usage guidance.
- [`fonts/`](fonts/) — Rubik (primary sans) and notes on self-hosting.

## Usage rules

- Do not distort, recolor, or re-type the logo.
- Use the provided project primary colors (sky, emerald, orange) for project identity; keep
  `neutral: slate` everywhere.
- Prefer SVG assets; raster versions should be exported from the SVG at 1× and 2×.
- Favicons and PWA icons are generated from `lcms-logo-mark.svg`.
